This is a tool I'm making to quickly judge a soccer game based on how entertaining it might be based on a score (not to be confused with the actual game's score) while spoiling as little as possible.

Some of the use cases of this tool are to check if a game is still competitive after the favorite team is winning by a wide margin, and you're considering checking out. You can check to see if the game had a high entertainment score, which would imply that the other team made a comeback in some capacity. If the game ends with many goals and the score is close, or if the underdog takes it to the favorite, you can expect to see a high score!  
You may have watched a couple games in a row with no goals, and while soccer is usually entertaining to watch regardless of the score you can easily know that the next match you watch will have at least one goal (if the score is 1 or greater, the match had goals).
While I wouldn't recommend checking this tool's results to pick a game to watch first, all the time, you can choose a game this way. The entertainment value of a game isn't all baked into the final score, even though at this time that's all this tool bases its signal off of.

My main goal with this tool is to make sure a great game doesn't pass by a soccer enthusiast, and I am aware that this goal might be impossible to achieve with the data and time I have available to make this, but I would at least like to generally throw a strong signal when a game is action packed and punctuated with goals and drama.
